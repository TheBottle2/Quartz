# Welcome to Quartz

This is your **vault** — a folder of plain-text Markdown files.

## Getting Started

1. **Create notes**: Press `Ctrl+N` or click the `+` button in the sidebar
2. **Link notes**: Type `[[Note Title]]` to create bidirectional links
3. **See backlinks**: The right panel shows all notes linking to the current one
4. **Live preview**: Toggle with the eye icon in the editor header
