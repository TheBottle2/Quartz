# Markdown Guide

Quick reference for Markdown syntax supported in Quartz.

## Headings

# H1, ## H2, ### H3 — up to six levels.

## Text

**Bold**, *italic*, ~~strikethrough~~, `inline code`.

## Links

Wiki-links connect notes: [[Welcome]], [[Getting Started]].

## Lists

- Unordered item
  - Nested item
- Another item

1. Ordered item
2. Second item

- [ ] Open task
- [x] Done task

## Code Blocks

```rust
fn main() {
    println!("Hello, vault!");
}
```

## Math

Inline $E = mc^2$ and blocks:

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

## Tags

Add `#topic` anywhere to tag a note: #guide #markdown
