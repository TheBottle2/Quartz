# Getting Started

Welcome to your knowledge base! This note explains the basics.

## Core Concepts

- **Notes**: Plain `.md` files in your vault folder
- **Links**: `[[Note Title]]` creates a connection
- **Backlinks**: Automatically tracked, shown in right panel
- **Tags**: `#topic` for optional categorization

## Creating Your First Note

1. Press `Ctrl+N`
2. Type a title (e.g., "My First Note")
3. Press Enter
4. Start writing!

## Linking Notes

Type `[[` and start typing a note name — autocomplete will appear (in future versions).

Click any `[[link]]` in the preview to navigate — try [[Welcome]] or [[Workflow Ideas]].

## Tips

- Use the preview pane (eye icon) to read rendered Markdown
- Backlinks update automatically when you save
- All data stays in your vault folder — copy it anywhere```
