# Workflow Ideas

Ways to use Quartzite for different workflows.

## Zettelkasten

- One idea per note
- Link liberally: `[[Related Concept]]`
- Use `#tags` for topics
- Create MOCs (Maps of Content) as index notes

## PARA Method

- **Projects**: short-term efforts with a goal
- **Areas**: long-term responsibilities to maintain
- **Resources**: topics of interest — see [[Markdown Guide]]
- **Archives**: inactive items from the other three

## Daily Notes

Press `Ctrl+Shift+D` for today's note, stored under `Daily/`.
Start from [[Getting Started]] if you're new. #workflow
